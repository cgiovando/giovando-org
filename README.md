# giovando-org

Source for [giovando.org](https://giovando.org), a personal website served by GitHub Pages.

## Purpose

A minimal static site with a home page, a water polo video page, a privacy policy and terms of service. These pages give the Google Cloud OAuth consent screen for my personal YouTube upload tool the home page, policy links and authorized domain it needs to run in production. A fuller personal website may follow.

## Structure

Plain HTML and one stylesheet, no build step. `CNAME` sets the custom domain.
